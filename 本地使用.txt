这个项目可在浏览器本地把图片增强到 2K / 4K，图片不会上传服务器。

1. 安装 Node.js：https://nodejs.org

2. 解压后进入 photo-2k 文件夹，打开终端：
     npm install
     npm run dev

3. 浏览器访问 http://127.0.0.1:43180
   选择或拖入图片，然后选择处理方式：
   - 经典高清：Lanczos-3 等比缩放，可调锐化，不会补画内容。
   - AI 超清：保留经典高清底图，只叠加克制的 Real-ESRGAN 高频细节层。

   选择 2K / 4K，处理完成后点击下载 PNG。

注意：AI 细节与原图冲突时会自动舍弃。首次使用需加载约 5MB 模型和约 26MB 推理组件，之后由浏览器缓存。
